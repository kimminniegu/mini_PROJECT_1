# 📓 JOB DIARY (잡 다이어리)

> **"오늘도 나의 취업 준비를 기록해요 ✏️"**  
> 싸이월드 미니홈피와 아날로그 다이어리 감성을 현대적으로 재해석한 취준생 전용 취업 준비 관리 웹 서비스

---

## 1. 프로젝트 개요

**JOB DIARY**는 취업 준비 과정에서 필요한 일정, 이력서용 고정 정보, 면접·자기소개서 결과 복기, 채용공고, AI 활용을 하나의 웹 서비스에서 관리할 수 있도록 하는 Flask 기반 팀 프로젝트입니다.

단순한 To-Do List가 아니라 다음 흐름을 하나의 서비스 안에서 연결하는 것을 목표로 합니다.

```text
오늘 해야 할 일 확인
        ↓
채용공고 및 마감 일정 관리
        ↓
이력 / 자기소개서 / 면접 준비
        ↓
지원 및 면접 결과 기록
        ↓
경험과 개선점 축적
        ↓
다음 취업 활동에 활용
```

### 타깃 사용자

- 취업 준비 일정이 여러 곳에 흩어져 있는 취준생
- 반복해서 사용하는 이력서 정보를 한곳에 보관하고 싶은 사용자
- 면접 및 자기소개서 결과를 기록하고 복기하고 싶은 사용자
- 관심 채용공고와 지원 마감일을 직접 관리하고 싶은 사용자
- ChatGPT, Gemini 등을 취업 준비에 더 효과적으로 활용하고 싶은 사용자

---

# 2. 핵심 콘셉트

JOB DIARY의 핵심은 **“취업 준비를 기록하는 디지털 다이어리”**입니다.

기존의 딱딱한 업무용 대시보드보다는 실제 다이어리를 사용하는 것처럼 편안하고 직관적인 경험을 제공합니다.

### 핵심 가치

- 📅 **일정 관리**: 캘린더와 To-Do를 이용한 취업 준비 일정 관리
- 🪪 **이력 관리**: 이력서 작성에 반복 사용되는 고정 정보 저장
- 🎤 **내용 복기**: 면접·자기소개서·전형 결과와 피드백 기록
- 💼 **채용공고 관리**: 직접 저장한 공고와 마감일 관리
- 🤖 **AI 활용 지원**: 외부 AI 바로가기 및 취업용 프롬프트 생성
- 📝 **글로벌 퀵 메모**: 어느 화면에서든 즉시 메모
- 🔮 **오늘의 운세**: 매일 접속하고 싶은 재미 요소

# 5. 메인 화면 (Home)

메인 화면은 다이어리의 첫 장처럼 구성하며, 사용자가 오늘 해야 할 일을 빠르게 확인할 수 있도록 합니다.

## 주요 구성

### TODAY

현재 날짜를 보여줍니다.

예:

```text
TODAY
2026.09.16
```

### 인사말

예:

```text
안녕하세요! 👋
오늘도 취업 준비를 시작해볼까요?
```

### 취준 현황 요약

간단한 카드 형태로 주요 정보를 보여줍니다.

예:

```text
TODO 3
저장된 채용공고 8
다가오는 마감 2
```

### TODAY'S TODO

오늘 해야 할 일정만 간단하게 보여줍니다.

```text
□ 자기소개서 작성
□ 기업 분석
□ 채용공고 확인
```

### 퀵 메모

메인에서도 바로 메모를 작성할 수 있습니다.

### 오늘의 운세

메인 하단에 운세 카드가 노출됩니다.

# 6. 글로벌 퀵 메모 (Quick Memo)

메모장은 별도의 메뉴로 분리하지 않고 **모든 페이지에서 사용할 수 있는 공통 기능**으로 구현합니다.

## 동작 방식

각 페이지에서 `[＋ 메모]` 버튼을 누르면 중앙에 작은 메모 모달을 표시합니다.

```text
┌──────────────────────────────┐
│ 📝 QUICK MEMO                │
│                              │
│ 내일 기업 분석 자료 정리     │
│ 꼭 챙겨보기                  │
│                              │
│ [ 저장 ]          [ 닫기 ]   │
└──────────────────────────────┘
```

## 저장 정보

- 메모 내용
- 작성 일시
- 작성 위치
- 수정 일시

예:

```text
[03 REVIEW]
A기업 면접에서 해외 경험 관련 질문 다시 정리하기
```

이를 통해 어느 화면에서 작성한 메모인지 나중에 확인할 수 있도록 합니다.

# 9. 02 HISTORY / 이력관리

이력서 작성 시 반복해서 사용하는 **고정 이력 정보**를 저장하는 화면입니다.

지원 현황을 관리하는 기능이 아니라, 사용자가 여러 회사의 이력서를 작성할 때 반복 입력해야 하는 정보를 미리 정리해두는 것이 핵심입니다.

## 관리 카테고리

### 기본정보

- 이름
- 생년월일
- 연락처
- 이메일
- 주소

### 학력

- 학교명
- 전공
- 입학일
- 졸업일
- 졸업 여부
- 학점

### 경력

- 회사명
- 근무기간
- 부서
- 직무
- 담당 업무
- 주요 성과

### 자격증

- 자격증명
- 발급기관
- 취득일

### 어학

- 시험명
- 점수 / 등급
- 취득일

### 프로젝트 / 대외활동

- 활동명
- 기관
- 기간
- 역할
- 주요 내용
- 주요 성과

## 주요 기능

- 정보 등록
- 정보 수정
- 정보 삭제
- 카테고리별 조회
- 카드 형태 정보 표시
- `[＋ 메모]` 버튼

## UI 방향

상단에 카테고리 버튼을 배치합니다.

```text
[기본정보] [학력] [경력] [자격증] [어학] [프로젝트/활동]
```

선택한 항목의 내용을 다이어리 카드처럼 보여줍니다.

```text
┌─────────────────────────────────────┐
│ 🎓 학력                             │
│                                     │
│ OO대학교                            │
│ 무역학과                            │
│ 2020.03 ~ 2026.02                  │
│                                     │
│              [수정] [삭제]          │
└─────────────────────────────────────┘
```

# 10. 03 REVIEW / 내용복기

취업 활동 이후의 결과와 경험을 기록하는 오답노트형 다이어리입니다.

면접뿐 아니라 자기소개서, 서류전형, 인적성 등의 결과도 함께 저장할 수 있습니다.

## 기본 정보

- 기업명
- 지원 직무
- 지원일
- 전형 종류
- 결과

## 전형 종류 예시

```text
자기소개서
서류전형
인적성
1차 면접
2차 면접
최종 면접
기타
```

## 면접 복기 정보

- 면접 날짜
- 면접관 질문
- 내가 한 답변
- 받은 피드백

## Self Evaluation

KPT 방식으로 정리할 수 있습니다.

- **Keep**: 잘한 점
- **Problem**: 아쉬운 점
- **Try**: 다음 지원 / 면접에서 개선할 점

## 자기소개서 복기

- 자기소개서 문항
- 실제 제출 내용
- 결과
- 잘된 점
- 아쉬운 점
- 다음 작성 시 개선할 점

## 주요 기능

- 기업별 기록 생성
- 직무별 기록 조회
- 전형별 기록 조회
- 최신순 정렬
- 수정 / 삭제
- `[＋ 메모]` 버튼

# 11. 04 JOB POSTING / 채용공고

사용자가 관심 있는 채용공고를 **직접 입력하여 저장하고 관리**하는 화면입니다.

외부 채용사이트의 전체 공고를 자동 수집하는 서비스가 아니라, 사용자가 실제 지원을 고려하는 공고만 개인적으로 관리하는 기능을 우선합니다.

## 저장 정보

- 기업명
- 채용공고명
- 지원 직무
- 직무 카테고리
- 근무지
- 채용공고 URL
- 공고 등록일
- 지원 마감일
- 지원 상태
- 관심 여부
- 메모

## 지원 상태

```text
관심
지원 예정
지원 완료
서류 합격
면접 진행
최종 합격
불합격
```

## 주요 기능

- 채용공고 직접 등록
- 수정
- 삭제
- 기업명 / 직무 검색
- 저장된 공고 내 직무 필터
- 관심 공고 표시
- 원본 공고 링크 열기
- 마감일까지 D-Day 표시
- 지원 상태 변경
- `[＋ 메모]` 버튼

## 직무 필터 예시

```text
[전체] [해외영업] [구매] [무역] [물류] [기타]
```

## 캘린더 연동

저장한 채용공고의 `지원 마감일`을 캘린더에 자동 표시합니다.

예:

```text
삼성물산 해외영업
마감일: 2026-09-30

→ 01 TODO / CALENDAR
→ 09/30 "삼성물산 해외영업 지원 마감" 표시
```

채용공고가 수정되거나 삭제되면 관련 캘린더 일정도 함께 반영되도록 구현합니다.

# 12. 05 AI / AI 도우미 & 프롬프트 가이드

AI 메뉴는 **외부 AI 바로가기 + 프롬프트 생성 챗봇**의 2-Track 구조로 구성합니다.

---

## 12-1. 외부 AI 바로가기

하이퍼링크 버튼을 통해 외부 AI 서비스를 새 탭으로 실행합니다.

기본 제공:

- ChatGPT
- Gemini

예:

```text
[ ChatGPT 바로가기 → ]
[ Gemini 바로가기 → ]
```

---

## 12-2. 취업 프롬프트 생성 챗봇

OpenAI API를 사용하지만 일반적인 취업 상담 챗봇으로 만들지 않습니다.

이 챗봇의 역할은 **사용자가 ChatGPT나 Gemini에서 바로 복사하여 사용할 수 있는 완성형 취업 프롬프트를 만들어주는 것**으로 제한합니다.

### 사용 흐름

```text
사용자 목적 입력
        ↓
OpenAI API가 목적 분석
        ↓
완성형 프롬프트 생성
        ↓
사용자가 프롬프트 복사
        ↓
ChatGPT / Gemini 바로가기
        ↓
외부 AI에서 프롬프트 사용
```

### 입력 예시

```text
해외영업 직무 자기소개서를 작성하려고 하는데
내 해외 경험을 강조하고 싶어.
```

### 출력 예시

```text
당신은 취업 자기소개서 작성 전문가입니다.

지원 직무: 해외영업
강조하고 싶은 경험: 해외 경험

아래 정보를 바탕으로 해외영업 직무에 적합한 자기소개서를 작성해주세요.
```

해당 작업을 수행할 수 있는 **좋은 프롬프트를 생성하는 것**이 챗봇의 핵심 기능입니다.
